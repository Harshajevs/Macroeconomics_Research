# Historical report material

The current report and its supported generation/verification workflow are in `../report/`.

`report_versions/` preserves the initial, revised, formal and clarity report packages as delivered. They have different wording, cover layouts or pagination and should not be mistaken for the current release. The earlier research checkpoints are retained separately in the repository's research directories.

`report_preparation/` preserves the editing and packaging scripts used between report versions. These scripts refer to the original session's `work/` and `outputs/` layout and are historical records, not the current build entry points. They are included to retain the project-specific code; the final report's portable scripts are in `../report/`.

Temporary renders, virtual environments, bytecode, unrelated course examples and private chat-context attachments are not part of the published project. The cancelled presentation work is also excluded.
