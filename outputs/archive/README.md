# Archived Stage-1/Stage-2 outputs

Files in this folder preserve earlier project artifacts for auditability. They are **not current inference outputs** and should not be cited in the final report without independent re-analysis.

In particular:
- Legacy YoY correlation and lead/lag tables use overlapping annual windows and are descriptive only.
- The legacy circular YoY bootstrap is superseded by the paired stationary bootstrap on STL-adjusted monthly log changes.
- Legacy Stage-2 ARDL/cointegration screens used the earlier 2014–2025 window and a 0–6 food-lag screening design. They are retained for audit trail only.

Use the current outputs in `outputs/tables/` and current design in `documentation/econometric_model_specification.md`.
